## **Part 1: Background Knowledge**

A Health Savings Account (HSA) is a tax-advantaged savings account. Individuals who are enrolled in a high-deductible health plan are eligible to contribute to an HSA. Their contributions are tax-deductible, their funds grow tax-free, and withdrawals for qualified medical expenses are also tax-free.

## **Part 2: Build an HSA Web Application**

### **Objective**

Create a web application that demonstrates the core lifecycle of an HSA: account creation, funding, card issuance, and transaction processing. This should include a customer-facing UI served as a website, and (at a minimum) a backend service with the APIs used by the web app.

### **Core Features**

Your application must allow a user to:

1. **Create an Account:** A simple user registration and creation of a new, distinct HSA account.
2. **Deposit Funds:** Add virtual funds to the newly created HSA.
3. **Issue a Card:** Emulate a virtual debit card that is linked to the HSA and its current balance.
4. **Validate Transactions:** Simulate a purchase with the card. Your application must validate whether the attempted transaction is for an IRS-qualified medical expense before approving or declining it.

### **Technical Requirements**

- **Must run locally:** We need to be able to run your code locally without any third-party services required. Readily available open source libraries are allowed. By following your [README.md](http://readme.md/) instructions, we should be able to run your application within a few minutes.
- **No Real Money:** Do not use actual money for this project.

**Note:** You are free to use any service that you wish to build this application. **AI is absolutely allowed, and encouraged.**
